# Touch

Touch 是一款记录真实见面关系的安卓应用，帮助你更清晰地整理好友、名片、日历见面记录和互动徽章，也支持把手机里的笔记照片快速打包成 ZIP 保存或分享。

## 主要功能

- NFC 碰一碰记录见面
- 好友搜索、申请、删除、屏蔽和备注
- 个人名片编辑
- 周 / 月 / 年日历查看
- 徽章成长系统
- 手机本地打包笔记照片并分享或保存

## 使用方式

### 安卓端

用 Android Studio 打开 `Touch/`，运行到模拟器或真机即可。

### 本地后端

```powershell
cd TouchBackend
python .\server.py
```

后端用于开发和测试，不是生产环境。

## 适合谁

Touch 适合想要：

- 记录真实见面的人
- 管理好友关系的人
- 用日历回顾互动历史的人
- 快速整理课堂笔记照片的人
