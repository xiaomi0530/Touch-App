# Touch

Touch 是一款面向真实生活记录的安卓应用，帮助你更清晰地记录“和谁在什么时候见过面”，整理好友关系，并把日常互动变成可回顾、可收藏的内容。

它包含：

- 基于 NFC 的“碰一碰”记录
- 好友管理与个人名片
- 周 / 月 / 年日历查看
- 可成长的徽章系统
- 手机本地打包笔记照片为 ZIP

## Touch 的感觉

Touch 的目标是做成：

- 上手快
- 视觉友好
- 一眼能看懂
- 围绕真实社交记录，而不是单纯打卡

## 主要功能

- 注册和登录账号
- 两台手机碰一碰，记录一次见面
- 搜索、添加、删除、屏蔽、备注好友
- 按周、月、年浏览见面历史
- 编辑个人名片，包括头像、简介、生日、性别和背景图
- 通过持续互动解锁并成长徽章
- 在手机上把课堂笔记照片打包成 ZIP，并分享或保存到本地

## 适合谁

Touch 适合：

- 想记录真实见面关系的人
- 想要更私密、更轻量社交记录的人
- 喜欢清爽日历和徽章展示的人
- 需要把手机照片快速整理成压缩包的人

## 本地运行

### 安卓端

用 Android Studio 打开 `Touch/`，运行到模拟器或手机。

### 后端

```powershell
cd TouchBackend
python .\server.py
```

后端用于开发和测试。
